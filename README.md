# Elixir Start

> 🧪 **Projeto de estudo** — primeiros experimentos com Elixir e programação funcional.

Repositório criado durante meus primeiros contatos com Elixir, com o objetivo de experimentar a sintaxe da linguagem e compreender conceitos de programação funcional.

Os exercícios foram desenvolvidos dentro de um projeto Mix e exploram principalmente operações com coleções, funções anônimas, transformação de dados e estruturas da linguagem.

## Conteúdo

- Operações com listas e maps;
- Uso do módulo `Enum`;
- `map`, `filter`, `reduce`, ordenação e remoção de duplicados;
- Pattern matching e `case`;
- Pipes (`|>`);
- Structs;
- Funções anônimas;
- Primeiros experimentos com o ecossistema Mix.

## Tecnologias

- Elixir
- Mix

## Status

📚 Repositório experimental mantido como registro do primeiro contato com Elixir e com o paradigma funcional.
